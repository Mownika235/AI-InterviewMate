# AI InterviewMate - Project Guidelines

## Project Overview

AI InterviewMate is a web application for practicing technical interview
questions based on job role and difficulty level.

## Project Structure

- frontend/ contains the user interface.
- backend/ contains the backend API and application logic.
- .kiro/specs/ contains feature specifications.
- .kiro/hooks/ contains Kiro automation hooks.
- .kiro/steering/ contains project guidance.

## Development Guidelines

- Keep the code simple and readable.
- Use meaningful variable and function names.
- Keep frontend and backend responsibilities separate.
- Test changes before committing.
- Do not commit generated files such as __pycache__ or node_modules.

## Frontend

- Use React for the frontend.
- Keep components readable and maintainable.
- Keep the UI responsive.

## Backend

- Use Python and FastAPI.
- Keep API endpoints clear and focused.
- Return appropriate responses and error messages.

## Git

- Check git status before committing.
- Use meaningful commit messages.
- Push completed changes to the main branch.

## Kiro

Use Kiro specifications, steering documents, hooks, and other Kiro
features when they provide meaningful value to the project.
